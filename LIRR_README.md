# LIRR access network (Section 4.2)

AM peak commuter market from Long Island census tracts to New York City. Two
operators (LIRR commuter rail, LOCAL feeder transit) plus an operator-less auto
alternative on the station-access leg and on the outside option.

897 nodes, 8,320 links, 2,275 owned links, 6 destination segments, 29,455
available segment-link cells of which 4,722 carry positive flow. Gross surplus
at the administered fares is $1,335,005/hr.

Provenance, including the note that the fares are stylized rather than a
published MTA schedule, is in the top-level README.md. Scripts expect to be run
with this directory as the working directory.
